# sumi-homepage

음악치료사 **정수미(Jeong Soo Mee)** 님을 소개하는 1페이지 웹사이트.
((사)한국음악치료학회 임상음악전문가 1급, 자격번호 제593호)

심상음악치료(GIM)를 중심으로 한 소개, 경력·자격, 프로그램, 자주 묻는 질문,
콘텐츠 활동, 후기, 문의 섹션으로 구성된 정적 HTML 사이트입니다.

## 미리보기

`index.html` 파일 하나로 완결됩니다. 브라우저에서 바로 열어 확인할 수 있습니다.

### GitHub Pages로 배포하기

1. 이 저장소 → **Settings → Pages**
2. **Source** 를 `Deploy from a branch` 로 설정
3. Branch: `main` / 폴더: `/ (root)` 저장
4. 잠시 후 `https://ryuheart-byte.github.io/sumi-homepage/` 에서 공개됩니다.

## 구조

| 파일 | 설명 |
|------|------|
| `index.html` | 사이트 전체 (HTML + CSS + JS 인라인, 외부 의존성은 Google Fonts뿐) |
| `assets/` | 배경·프로필 사진 (교체 방법은 `assets/README.md`) |
| `README.md` | 이 문서 |
